LAB 02  /  ENCRYPTION
تشفير حقيقي أمامك
اكتب رسالة تجريبية، ثم شفّرها بخوارزمية AES-256-GCM عبر متصفحك، وحاول فكها بالمفتاح الصحيح أو الخاطئ.

LAB 03  /  PASSWORD HASHING
كلمات المرور ليست رسائل مشفّرة
التشفير يمكن فكه بالمفتاح، أما تخزين كلمات المرور فيحتاج خوارزمية تجزئة بطيئة ومخصّصة مثل bcrypt أو Argon2id.

          
✕
MD5 / SHA-256
سريعة جدًا وتسمح بتجربة أعداد ضخمة من التخمينات؛ غير مناسبة مباشرة لتخزين كلمات المرور.
✓
bcrypt / Argon2id
خوارزميات مخصصة لكلمات المرور مع Salt وعامل كلفة؛ للمشاريع الجديدة غالبًا يُفضّل Argon2id عند توفره.

          
▣
تجربة Hash تعليمية
نستخدم SHA-256 فقط لتوضيح أثر الـ Salt، وليس لتخزين كلمات المرور.
اختر التشغيل لتشاهد قيمتين مختلفتين لنفس النص.

          
⚙
تجربة PHP حقيقية (مرفقة)
الملف المرفق يعمل محليًا ويستخدم password_hash / password_verify الحقيقيتين.
$hash = password_hash($password, PASSWORD_BCRYPT);
$valid = password_verify($input, $hash);
01 شغّل خادم PHP محليًا.
02 افتح php-labs/password-demo.php.
03 لاحظ اختلاف Hash في كل مرة ونجاح التحقق.
افتح مختبر bcrypt (يتطلب PHP)

          
الفرق في سطر واحد
Encryption → يمكن استعادة البيانات بالمفتاح. Hashing → لا يوجد فك تشفير؛ نتحقق من التطابق بعملية verification. ولا يعني ذلك أن كلمات المرور الضعيفة لا يمكن تخمينها.

ABOUT  /  THE PROJECT
تعلّم بالتجربة، لا بالمشاهدة فقط
مشروع بونص تعليمي لمساق Web Security. هدفه تبسيط أفكار المحاضرات بتمارين قصيرة قابلة للتجربة والمشاركة مع الطلبة.
الأهداف التعليمية
  • شرح خطورة دمج مدخلات المستخدم مباشرة داخل استعلامات SQL.
  • توضيح دور Prepared Statements في فصل الأوامر عن البيانات.
  • تنفيذ تشفير وفك تشفير حقيقي بالمفتاح الصحيح.
  • تمييز Encryption عن Password Hashing ودور Salt.
  • قياس الفهم بأسئلة ذات تغذية راجعة فورية.
النطاق والخصوصية
  • المحاكاة خاصة ببيانات وهمية، ولا تختبر مواقع حقيقية.
  • التشفير يتم داخل المتصفح باستخدام Web Crypto API.
  • لا توجد حسابات مستخدمين أو إعلانات أو تحليلات أو اتصالات API.
  • تطبيق PHP اختياري ضمن الملفات لمطابقة مختبرات المحاضرات.
  • الاختبار التعليمي ليس شهادة أو تقييمًا جامعيًا رسميًا.
مصمم لظروف الاتصال غير المستقر
النسخة الأساسية ملفات ثابتة، يمكن تشغيلها بدون استضافة، ويصبح المحتوى متاحًا دون اتصال بعد تحميله.
المادة المرجعية: Web Security Overview، Encryption & Decryption، Encrypted Password، SQL Injection (محاضرات المساق المرفقة).
