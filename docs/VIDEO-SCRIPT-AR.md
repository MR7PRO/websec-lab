# 📱 WebSec Lab v2 — سكربت فيديو جاهز للقراءة من الجوال

**الهدف:** 3 دقائق تقريبًا — عرض جهاز الكمبيوتر + قراءة من الجوال.

## 🎬 1) المقدمة (15 ثانية)
🎙️ **احكي:** «السلام عليكم أستاذة آلاء. هذا WebSec Lab، مشروع تعليمي تفاعلي عملته حتى أشرح مفاهيم أمن الويب عمليًا وأساعد زملائي على مراجعة المادة، خصوصًا مع مشاكل الإنترنت.»

🖱️ **اعرض:** الصفحة الرئيسية وشعار المشروع.

## 🛡️ 2) SQL Injection (40 ثانية)
🎙️ **احكي:** «هذا مختبر محاكاة آمنة، ما بفحص مواقع حقيقية. بجرب الدخول الطبيعي، وبعدين محاولة حقن تعليمية. النموذج الضعيف بدمج مدخلات المستخدم مع SQL؛ بالمقابل النموذج المحمي بفصل البيانات عن الكود باستخدام Prepared Statements. النتيجة بتبيّن الفرق جنب بعض.»

🖱️ **اضغط:** SQL Injection → Correct login → Simulated injection → Compare both approaches.

## 🔐 3) AES (35 ثانية)
🎙️ **احكي:** «هون تشفير AES-256-GCM الحقيقي داخل المتصفح. بضغط تشفير، وبعدها بفك النص بالمفتاح الصحيح، لكن لو غيرت المفتاح العملية بتفشل. وأرفقت مثالًا بلغة PHP لـ AES-256-CBC مثل المحاضرة، للتشغيل محليًا.»

🖱️ **اضغط:** Encryption Lab → Encrypt → Decrypt → غيّر كلمة المرور → Decrypt.

## 🔑 4) Password Hashing (25 ثانية)
🎙️ **احكي:** «هنا بشوف الطالب الفرق بين Encryption وHashing، ودور الـSalt. مثال الـSHA-256 للتوضيح فقط؛ أما مثال PHP المرفق فبستخدم bcrypt وpassword_verify لحماية كلمات المرور.»

🖱️ **اضغط:** Password Safety → Generate two salted values.

## 🧠 5) بنك 60 سؤالًا — أهم جديد (40 ثانية)
🎙️ **احكي:** «طورت بنك الأسئلة ليصير **60 سؤال بالعربي والإنجليزي** موزعين على ستة موضوعات: SQL Injection، التشفير، كلمات المرور، أساسيات الويب، اختبار الاختراق، والحماية. الطالب بختار موضوعه وعدد الأسئلة 5 أو 10 أو 20 أو الكل، وبياخد تصحيحًا وتفسيرًا فوريًا، وبقدر ينزل نتيجة الاختبار بدون حساب.»

🖱️ **اضغط:** Knowledge Challenge → اختر Passwords / 5 Questions → Start → جاوب سؤال أو اثنين → انتقل للنهاية بسرعة بتصوير منفصل أو اعرض نتيجة جولة سابقة.

## 🌐 6) GitHub + Netlify + الخاتمة (25 ثانية)
🎙️ **احكي:** «الموقع مبني بدون Back-end أو تسجيل مستخدمين، وبشتغل على استضافة Static HTTPS مثل Netlify، ويمكن استخدامه بعد أول تحميل بدون إنترنت. الكود المصدري والتقرير مرفقين، وأتمنى يُنظر إليه كبونص تعويضي بعد انقطاع الإنترنت خلال الكويز. شكراً إلك.»

🖱️ **اعرض:** الموقع المنشور بعد تحققك من رابط Netlify الحقيقي، ثم صفحة About. **لا تدّعِ النشر إذا لم يتم الربط بعد.**

## ✅ قبل التصوير
- افتح نسخة Netlify عبر HTTPS عند توفر الرابط، أو نسخة `localhost` مؤقتًا.
- فعّل وضع عدم الإزعاج وأغلق التبويبات الحساسة.
- استخدم 1080p / 30fps إن أمكن.
- لا تدخل كلمات مرور حقيقية أو تفحص أي مواقع خارجية.
- سلّم MP4 + رابط Netlify بعد النشر + ZIP + تقرير PDF.
